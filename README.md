The growing adoption of electric vehicles (EVs) is creating new challenges for existing power systems, particularly in terms of increasing electricity demand and grid stability. Vehicle-to-Grid (V2G) technology offers a promising solution by allowing electric vehicles to act as flexible energy resources that can both draw power from and supply electricity to the grid. The effectiveness of this technology largely depends on the control strategy used to determine when vehicles should charge, remain idle, or discharge energy. The proposed controller uses several key parameters as inputs, including the battery’s State of Charge (SOC), grid load, EV power demand, battery temperature, and time. Based on these inputs, the agent selects an appropriate action: charging, idling, or discharging. The reward function is designed primarily to balance grid demand and reduce peak loads. The performance of the proposed DQN-based controller is evaluated using a V2G dataset in a simulated environment. Its effectiveness is compared with three scenarios: a system without V2G support, a rule-based control strategy, and a traditional Q-learning approach. In addition, several machine-learning techniques, including Linear Regression, Decision Tree, Random Forest, XGBoost, and Long Short-Term Memory (LSTM), are examined separately for electricity load prediction and active V2G control. The simulation results illustrate how the DQN agent learns through interaction with the environment and adapts its charging and discharging decisions to different operating conditions. This study focuses on the software development and simulation aspects of the V2G system. Further work will explore battery performance under practical operating conditions and the real-time implementation of the proposed controller using hardware.
